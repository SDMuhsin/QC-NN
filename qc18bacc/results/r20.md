# R20: act block qb_act2_blk timing (opt-in QB_ACT_S1T) on top of R19's QB_ACT_S1P

Labels: [M] measured by my scripts on tool output, [S] tool-reported, [E] estimate / model, [R] recommendation.
Scripts `impl/r20/`, summaries `results/r20/`.  Build on tau3 `$QC_BUILD/{syn,pnr}/r20_*`.  Target changed mid-round by the
PI: 2.30 ns (>= 435 MHz tt, aim ~450) instead of 489.6 MHz; sign-off PT at 2.30 ns from then on.

**Result (negative on fmax, complete on sign-off):** r20_c (QB_ACT_S1T, die 900 x 1970) is **DRC-clean (0 markers after 32 DR
iterations), antenna-clean (0 net / 0 pin), GRT 0.25 overflow 0**, abstracts written; but **PT tt @2.30 reg2reg 412.1 MHz,
all-path 383.7 MHz** (target 435), ss reg2reg 242.7 MHz.  R19's r19_mc at 2.30: reg2reg 427.0, all-path 384.1 (tgo).
The RTL change (designed for 489.6 before the target change) moved the critical paths instead of removing them; the P&R
IO-latency correction (QB_IO_LAT 0.55 -> 0.77) fixed the input side but made the post-CTS hold repair buffer all 4 608
act outputs.  Cheapest path to 435 / 450 is in section 6.

## 3. RTL: opt-in `QB_ACT_S1T` (needs QB_ACT_S1P; defaults unchanged)

* `hw/tb/gen_act2_s1t.py` (imports gen_act2_s1p / s2m; checks every term in exactly one partial and every partial reaching
  its home register exactly once) -> appended by `hw/tb/gen_act2.py` to `hw/rtl/qb_act2_net.sv` inside `ifdef QB_ACT_S1T`
  (pre-existing file content byte-identical).  Grouped sides: `hw/tb/qb_act2_s1t_grp.txt` (from s1tree.py --grp).
* Changes vs S1P (same band map, terms, conditions, register stage; no cycle added):
  1. band-local select copies selt[b] = sel1a | sel1b (39 b), sel2t[b] (11 b), loaded with the same next-state values
     (removes the 0.40 ns broadcast after the flop);
  2. pre-mux select 4 x per band (s1t_c, 64 flops; qba2_pm_q 256-b instances) instead of s1c_r[b] per 1 024 b;
  3. shift select per band shqt[b] (3 b x 16 x 2 ctx) from shq's next-state; qba2_lb_t shifts word j with shqt[pj[j]];
  4. paired OR stops on the 38 grouped sides; inter-band nets connected in the wrapper (no feed-through ports).
* qb_act2.sv: `ifdef QB_ACT_S1T` blocks (copies + sim-only equality checks QBA2_S1T_ERR, off with QBA_S1T_NOCHK; S1 and lb
  instance switches).  DC hook `impl/r20/topo.tcl`: no register merging of the 960 copies.  Cost: +960 flops (1.7 % of 55.5 k).
* Mutants: QBA_MUT_S1T (reg 81 express partial in band 0 drops term G 162); QBA_MUT_S1TQ (band 3 never shifts).

## 6. Conclusions [R]

* Sign-off flow complete for r20_c (DR 0, antenna 0, PT tt / ss / hold, abstracts) but fmax is below R19 and below 435.
* At 2.30 R19's r19_mc only misses on 3 s1c -> s1 endpoints (-0.042) and the tgo cin class (-0.304, 0.39 ns of it hold
  buffers from the QB_IO_LAT mismatch).  The cheapest fix for 435-450 is therefore **no RTL change**: R19's netlist
  (r19_s1q) re-run from CTS with (a) QB_IO_LAT 0.77 for the input delays (removes the tgo hold buffers) but output hold
  kept as R19 (no act-output hold repair until the PI decides the column-side hold budget), (b) P&R period 2.10 for setup
  margin on the S1 cascade.  QB_ACT_S1T stays opt-in and is not recommended (paired stops with D1 cells on 2-band hops,
  shqt adds tgo load; the s1t_c / selt copies gave no measurable launch-side gain).  Needs P&R + 2.5-h DR (~3 h).
* tgo is combinational at the top (0.49 P measured in R14 r14_k > the 0.40 P budget): registering tgo in seq (+1 cycle on
  the token path; cycle cost for the user) or a top-side retime is the only constraint-honest end to the cin class.
