## 3. Residual markers: root cause and ECO (opt-in impl/r28/pin28.tcl, eco28.tcl/.sh, hop28.py) [M]
- h150, all 26 markers: M3 "NS Metal" at macro signal pins. The same pins fail on every instance: qb_i_128x128m1 D[27],
  D[69], Q[12], Q[69], Q[92] (4 image macros) and qb_p_240x144m2 EMA[1] (9 params macros). h125 has the same 26 plus
  1 M2 short (net243529 x net257073, the qb_f D[39]/D[40] input nets crossing at 382.7, 731.8).
- Mechanism: each failing 0.13 um pin lies under a 1.0 um M4 strap of the macro PDN, so no VIA34 can land in the pin.
  DRT therefore reaches the pin planar on M3, and because the pin is off-track, wire and pin overlap only 0.06-0.07 x
  0.065 (< min width 0.10). Clean neighbours such as D[26] use a VIA34 in the pin. This does not depend on std-cell
  density. Root fix for later: keep macro-PDN M4 straps off signal pins (a pdn_macro offset or keep-out).
- ECO, NS Metal: an M3 segment on the wire's x over the full pin height (ends flush with the pin). check_drc 26/26
  before, 0/26 after. A RECT patch does not help, because check_drc in this build ignores RECT patches.
- ECO, short: hop28.py re-encodes the net243529 wire with a via hop down to M1 (VIA12 at y 731.5 / 732.1). An M3 hop would
  short the qb_f VSS ring. Result: 0 in all 27 marker boxes.
- Full-die check_drc after the ECO: h125 9, h150 11. All were present before the ECO and none is in DRT's own count. 8 of
  them (h125) are same-net spacing or cut at DRT's RECT patches, which check_drc does not load. h125 has 1 two-net marker:
  VDD macro pin vs net242955 on M3, spacing 0.42 um at a 1.54 um run; it may be real. Moving that segment created
  shorts, so the move was reverted (open item).
## 4. Antenna after DR (the blocker) [M]
- GRT-time repair reports 0, but check_antennas on the routed die finds 746 nets / 862 pins on h125 and 1089 / 1237 on
  h150. All are CAR (limit 5000) on M4-M8. Ratio / limit (h150): 66 % below 1.25, 24 % 1.25-1.5, 9 % above 1.5 (max 3.26).
- 962 of the 1237 h150 pins are macro inputs (qb_s 398, qb_p 272, qb_b 271; LEF gate area 0.009-0.018 um2). The rest are
  AOI22D0 127, DFQD1 98 and ND2D0 31. ND2D0 -> ND2D1 is footprint-identical, AOI22D0 -> D1 is not, so a cell swap cannot
  clear these.
- Post-DR repair_antennas fails (GRT-0221 "Cannot create wire for net N157", a port net), and DRT cannot re-read its
  own routed db (DRT-1010 non-orthogonal wire x 103). No incremental DR or diode ECO is possible in this build.
- **Why r28_h125a / r28_h100a existed:** they were hedges for the antenna blocker. Each re-ran prod from cts.odb
  (run24.sh mk) with opt-in QB28_ANT_MARGIN 70 (repair_antennas -ratio_margin in impl/r21/post_grt.tcl), then DR, as the
  only antenna fix this build allows. Result on h100a [M]: GRT saw only 9 violations and inserted 25 diodes (vs 1089
  DR-time violating nets on h150). The GRT ratio underestimate exceeds any margin, so both runs were killed (09:3x UTC)
  and deleted.
- Next [E]: the antenna needs diodes on the macro inputs and long-net sinks based on DR routes. Options: a newer OpenROAD
  (post-DRT repair_antennas + incremental DR, as in ORFS), unconditional diodes on all macro input pins before DR, or
  antenna-aware layer assignment (GRT -> higher layers for macro-pin nets).
