# R13: act-supply hard block qb_act2_blk -- QB_ACT_RPL (s1c replicas, registered write-slot enables) + M2-short root cause

**[S]** DC / OpenROAD / PT, [OR est.] OpenROAD STA, [M] measured on R9a data.  Flow `impl/r13/` (imports impl/r9a), data `results/r13/`.
**Result (partial):** RTL QB_ACT_RPL bit- and cycle-exact (10 / 10 images, 2 mutants caught), DC +0.03 %.  Chip-cone block (PI
addendum) routed at 900 x 1970 to DR iteration 0 only: 1.72 M markers (R9a 2.21 M, -22 %), PT 407.6 / 264.5 MHz tt / ss on the
unclean route (R9a 344.3 / 251.4), target 520 not met, **not DRC-clean**.  M2-short mechanism measured: S1 AOI22 pin density.

## 1. RTL: opt-in `QB_ACT_RPL` (hw/rtl/qb_act2.sv; default build unchanged)

(a) **s1c replicas.**  `s1c_r[15:0] <= {16{is_v[1]}}`, copy k selects pre-mux region `lbm[1024k +: 1024]` (`qba2_pm_r`, 16
instances).  N = 16 = one per 1 k pre-mux bits.  In synthesis only 10 copies survive: lbm[16383:10240] (line-buffer slots 5..7
seen through the pre-mux) has no S1 load in the row-homed S1 (qba2_s1r), so DC removes regions 10..15 with their copies -- the
same as the 16 k-bit qba2_pm, whose upper 6 k bits were already dead.  No merging: impl/r13/topo.tcl
`set_register_merging false` on the 272 replica flops (`*s1c_r_reg*`, `*wer_reg*`; no dont_touch, so their fanout is still
sized / buffered).  Netlist: 10 s1c_r + 256 wer flops present.
Region choice [M]: the lb bit -> S1 register map (gen_act2_s2m.py) is not spatially coherent -- each 32-b lb word feeds
S1 registers of 22-34 of the 16 act rows -- so no index grouping is also a physical grouping; a copy per 1 k bits cuts the
fanout 16 k -> 1 k (buffer tree depth -2) and lets the placer put each copy at its group's centroid.

(b) **Write-slot decode one cycle early, registered, replicated.**  `wer[r][s]` (r = 0..15 = 128-b region of a slot, quarter
r / 4; s = slot) registered per context = 128 flops / context, each driving 128 lb bits (was: one ev2 / vb / rcnt decode ->
2048-b slot enables across the block).  Operands one cycle early: `ev2 <= ev1` unconditionally, so ev2's fields are ev1's
a cycle earlier; vb and rcnt are taken as their **next-state** values, written as register-only candidates selected by the
sequencer's own update conditions: `clr` = S_IDLE & start (vb = rcnt = 0), `vb_inc` = S_BIN & is_v & last chunk & last ct
& (cfg != 0 | tile[0]) (vb + adv), `rc_inc` = relgo (SRA; else S_INT & is_v & !is_zero) (rcnt + irel).  Only bits [2:0]
matter (slot index), so the candidates are 3-b subtractions; the late selects (is_v / relgo carry tgo) meet the final mux.
Exactly cycle-neutral (same lb contents every cycle): checked by a sim-only shadow assertion (`QBA2_RPL_ERR`, wer vs the
old ev2 decode every cycle; `QBA_RPL_NOCHK` disables it) and by the bench.

**Verification** (results/r13/tb.txt; full chip bench, define set of the brief + QB_ACT_RPL, progc):
* QB_ACT_RPL: **10 / 10 val images PASS** (s0 img60/61/0/1/2, s1 img13/55/7/42/91), logits 100/100 exact, cycle_mismatch 0,
  intervals identical to R10a (3780 / 3748 / 3748 / 3788; 3836 / 3764 / 3732 / 3796), 0 QBA2_RPL_ERR.
* default build (no QB_ACT_RPL): s0 img60 + s1 img13 PASS, same cycles.
* mutant QBA_MUT_RPLC (copy 5 loaded from is_v[0]): FAIL, err 100 logits, cycle_mismatch 40 (both images).
* mutant QBA_MUT_RPLW (window-advance candidate dropped): shadow assertion fires (cycle 169 355); with the check off
  (QBA_RPL_NOCHK) still FAIL, err 100, cycle_mismatch 30 / 40.

**DC** (results/r13/dc.txt, tt 1.65 ns, topo): 819 432 um2 (+230, +0.03 %), +260 regs, DRV nets 63; PT tt / ss 599.2 / 384.7
(R9a 601.6 / 383.6; worst lval -> m_ra unchanged, R8a domain); lb_reg class tt 602.2 -> 631.0, ss 420.6 -> 422.9.

## 2. Where the R9a DR M2 shorts are (mechanism) [M]

`impl/r13/cell_dump.tcl` (odb -> master, box, signal pins per instance) + `impl/r13/m2_short.py` (10-um bins, M2 short markers of
`drt.drc.rpt` vs cell classes), on R9a r9a_f2j (results/r13/m2_r9a_f2j.txt; same bins with the placement after the place step:
m2_r9a_f2_place.txt):

| M2-short decile (bins) | shorts / bin | share of 1.03 M | cell util | signal pins / um2 | S1 share of cell area |
|---|---|---|---|---|---|
| 0-1 | 0-1.5 | 0.2 % | 0.42-0.64 | 0.13-0.25 | 1-2 % |
| 4-5 | 22-36 | 8 % | 0.83-0.84 | 0.62-0.65 | 1-2 % |
| 8 | 172 | 23 % | 0.86 | 0.77 | 23 % |
| 9 | 330 | **45 %** | 0.86 | **0.99** | **59 %** |

* The shorts follow the **signal-pin density**, not the global utilisation (block 0.62): 45 % sit in the 10 % of bins where
  S1 AND-OR cells (`u_s1`: AOI22D1 13.7 k, AOI211, ND4; top-1 % bins = 1 782 AOI22D1 of ~2 900 cells) are 59 % of the
  area at local utilisation 0.86 and ~1 pin / um2.  AOI22D1 (5 pins on M1) is reached through M2: M2 demand = pin count.
* The 0.86 is made after global placement: gpl spreads to 0.65, the incremental gpl after DRV repair 1 to 0.71, and
  repair 2 + CTS + hold insertion (+0.16 mm2 = +17 %) are only legalised in place -> 0.83 at place (m2_r9a_f2_place.txt),
  0.86 after CTS / hold.  The S1 cluster itself is dense by construction (row-homed S1: 4 096 regs with 7-23 AOI22 terms each).
* Not the pre-mux (2-6 % of hot-bin area), not the clock (0.9 % of markers), not PDN (1 %).

**Fix applied (r13_p1):** DPL cell padding 1 site left / right on the 43.9 k S1 cells (`impl/r13/pad.tcl`, re-applied before
the post-CTS DPL since padding is not stored in the odb) + gpl density 0.65 -> 0.55 (incremental 0.71 -> 0.61) so the padded
S1 cells find room.  Effect at CTS (pin-density deciles, no route yet): top decile 1.13 -> 0.98 pins / um2 (pad 2: 0.95),
decile 8 0.91 -> 0.78, hot-bin util 0.89 -> 0.79; S1 share of the top decile 0.38 -> 0.26.  Costs: DRV nets before repair
12.5 k -> 15.3 k (longer wires), cell area after CTS 1.068 -> 1.114 mm2 (util 0.639), post-CTS @2.0 pre-repair -0.486 / 1 809 ep
-> -0.381 / 841 (RPL removes the s1c / wsl paths), after repair -0.218 -> -0.116.  Pad 2 (r13_p2): same density gain,
worse timing (place WNS @1.85 -0.93 vs -0.51) -> pad 1 taken to route.

## 3. PI addendum: chip-cone wrapper + R11 floorplan pins

* **Wrapper** `impl/r13/qb_act2_blk.sv` (impl/r7c untouched; default = R7c, ACT_PIPE 2): opt-in `QB13_BLK_CHIP` =
  `qb_act2 #(.ACT_PIPE(1)) u_act` + `qb13_dreg #(4608) u_dist` on act only (= qbt_dreg, local copy so qb_top.sv is not
  read by DC) = qb_chip's `qb_top #(DIST 1, AP 1)` u_act + g_dist[0] exactly; done / busy / a_* / d_* now leave at the

  qb_top).  Filelist `impl/r13/qb_act2_blk_chip.f`, syn `QB13_FL=qb_act2_blk_chip.f QB_SYN=r13_actc QB9_CTL_SIDE=B`.
* **Pins** `impl/r13/pins.tcl` (`QB13_PINS=1`): act east as R9a; **all other pins south** (none north; DC topo port side B
  too).  s_q order rule: hub pin `u_top_s_q[m]` sits at x = 24 + 0.4 (16 (m % 128) + m / 128) (impl/r10b/pins10.tcl,
  j-major); the block has no WB_COL, so its s_q[n] = s_qt[n] = hub s_q[m] with n = 128(4G+b) + 32q + 8a + i <->
  m = 128(4G+a) + 32b + 8q + i (qb_act2.sv s_qt formula); block pin n is fixed on M6 at the x of hub pin m
  (QB13_SQX0 = 24, both blocks at the same chip x) -> all 2 048 block-to-hub s_q wires are straight verticals.
  m_q / ports / controls: place_pins on M2-M5 along the south edge (the hub's m_q pins have no fixed order either).

## 5. What remains, with mechanism [R]

1. **M2 shorts are S1-intrinsic.**  After padding, the hottest decile (46 % of M2 shorts) is still 57 % S1 cells at 0.82 pins/um2
   (m2_r13_c1d.txt): 1-site DPL padding lowers the pin density only ~14 % because gpl does not see per-instance padding and the
   repair 2 + CTS + hold insertion (+0.17 mm2) lands after the last spread.  Next levers, in order of expected effect: (a) let the
   block route on M8 (M2-M8, PDN / top on M9: vertical escape over the S1 cluster, no area); (b) re-spread after CTS (incremental
   gpl at the final cell area, then DPL with padding); (c) S1 restructure so each s1_reg is a registered-select mux of fewer wide
   terms (fewer AOI22 pins per bit).  Then >= 6 DR iterations (~45-55 min each here).
2. **Fmax:** s1c copies grouped by lbm index are not spatial groups (one lb word feeds 22-34 act rows) -> group the pre-mux by
   S1 home row instead (copy k drives the lbm bits whose S1 consumers sit in act rows 2k..2k+1; needs the generator's RL table),
   and register tgo before the wer select (or take vb_inc / rc_inc without tgo and correct a cycle later) for the cin2reg class.
