## Fixes (root cause -> fix) [S]
1. **PG pins** - root cause: icc2.cfg PDN_MESH kept the pdngen numbers (offset 5) but ICC2's mesh offset is the strap
   centre and its pattern nets were {VDD VSS}: VDD centred at 10 (9.6-10.4) instead of VSS 10.0-10.8; and
   `design_boundary_and_generate_pin` made 0.8 x 0.8 um pins at the die edges only, while the top (pdn_macro.tcl,
   macro_blk M7 -> M8) and the reference / act LEFs use full-width M7 straps as pins.  Fix: `floorplan/pg_grid.tcl` = the
   one chip grid (pdngen convention, M4 0.4/20/2, M7 0.8/30/5, VSS first) used by icc2/floorplan.tcl and the OpenROAD
   pdn_m8.tcl / pe_pdn.tcl; ICC2 offset = off + w/2, nets {VSS VDD}, straps stop at the die edge, `create_terminal
   -of_objects` of the M7 strap shapes; gate `qb_pg_check` (layer, net, width, full die width, exact low-edge list =
   offset + pitch) in floorplan and abstract.  COL_REFLEF / COL_TILES / COL_GADJ_L removed (gate uses pg_grid.tcl).
   Side find: terminals have no `layer_name` attribute, so abstract.tcl's act/act_o pair layer check compared "" to ""
   since R59; now `layer.name`, empty layer fails, and the abutment check errors instead of only logging.
2. **act driving cell** - io_budget.tcl `qb5_act_drv` (leaf driver of the own act_o[b] net: lib cell + pin, per bit)
   / `qb5_act_drv_apply`; ICC2 `qb_io_drive` (P(IO_DRIVE), every scenario) at init and inside qb_io_load (cts, route),
   PT col_blk.tcl after the IO budget (so drv_eco / DMSA inherit it).
3. **Port antenna** - route: `route.detail.default_port_external_gate_size` = min cell-LEF ANTENNAGATEAREA (0.018 um2),
   outside diode none (float).  Probe on r65 eco [M]: check_routes ZRT-311 100 -> 0.  Abstract: `qb_antenna_rules` +
   create_frame + `derive_hier_antenna_property` + write_lef: LEF 5.8 ANTENNAPARTIALMETALAREA / SIDEAREA / CUTAREA,
   GATEAREA, MAX*CAR per layer; gate in abstract.tcl.  The column no longer uses blkant.py / blkant.txt; out/<top>.lef
   is the antenna LEF (top run.sh / top.env read it).  blkant.py + blkant.tcl kept: hub / act run.sh (OpenROAD-era
   views) still call them - remove when those blocks move to ICC2.
4. **PT noise / pulse** - common.tcl `qb_pt_si_checks` (update_noise, report_noise -all_violators, report_constraint
   -min_pulse_width / -min_period) in col_blk / act_blk / hub / top_chip; QB_PT_SIGNOFF line gated by env.sh qb_pt;
   drv_eco.tcl: update_noise in the setup + `fix_eco_drc -type noise`, noise count in eco_summary.  run.sh post reports
   all three corners before failing.  r65 tt probe of the ECO [M]: 7 -> 5 -> 1 noise violators in one fix pass.
6. **ETM derate** - see below.  **Kit dont_use** - `*D20 *D24 BHD` (RN_TCBN65GPLUS_140B section 5.IV, Notes 2 / 4) in
   site.tcl (local + tau) and the example.

the final cells.  Fix: drv_eco.tcl gets fix_eco_timing -type setup (size_cell / BUFFD2-8) between DRV and hold; each
round re-measures the drivers, so the upsizing converges (stronger driver -> shorter own arc and stronger act drive).
