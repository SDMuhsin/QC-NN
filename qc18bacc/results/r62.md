## Fixes (root causes)
1. **Feedthrough buffers** [M]. Nothing protected the 4608 DC `BUFFD2/3/4 U*` (act[i] -> act_o[i]), so place_opt
   removed them. Fix: `icc2/init.tcl` sets `set_size_only` on the driver cells of `P(FEEDTHRU)` (`blocks/col/icc2.cfg`:
   `act_o[*]`). It errors unless there is exactly one driver per port; r62 has 4608 cells for 4608 ports.
   - Why size_only: it forbids removal but still lets ICC2 and PT resize the buffer for timing/DRV. dont_touch would
     also freeze the size. Neither blocks buffering of the net.
   - New gate `signoff/portcheck.py`, run by `run.sh` after every outputs step (pnr and eco). It fails on any
     port-to-port assign, or on a port-bit count that differs from the DC netlist.
     - r59: FAIL, 4608 assigns.
     - r62 route, eco1 and eco2: OK, 12354/12354 bits (+ VDD/VSS = 12356), 0 assigns.
2. **Antenna diodes** [M]. The bare name `ANTENNA` is the form ICC2 wants (man page; a test with `lib/ANTENNA` gives
   ZRT-302). The real cause: the kit LEF declares ANTENNA as `CLASS CORE`, not `ANTENNACELL`. The NDM therefore built
   it as an ordinary cell with `pin I is_diode false`.
   - Fix: `icc2/libs.tcl` sets `design_type diode` on the cell and `is_diode true` on the pin before
     commit_workspace. The shared NDM was rebuilt.
   - Routed test design: with design_type alone, ZRT-302 remains; adding is_diode removes it.
   - r62 route.log: 0 ZRT-301/302 (r59: 3), "INIT FILTER FOR DIODE LOCATIONS" present.
3. **SI** [M].
   - ICC2: `qb_timer` sets `time.si_enable_analysis true`, which also turns on coupling-cap extraction
     (`extract.enable_coupling_cap true`). route.log has 0 ROPT-002. The SPEF now has coupling entries (>1.25 M in
     the first 200 MB of the ss SPEF).
   - PT: `signoff/pt/common.tcl` sets `si_enable_analysis true`. col_blk.tcl and act_blk.tcl now source it before
     read_parasitics, otherwise PT grounds the coupling caps. The PT log shows 2 XTALK-001 iterations (r59: 0).
4. **SDC** [M]. `common/block_sdc.tcl` now deletes the set_load/set_resistance lines together with their newline.
   init.tcl got the same fix for its op-cond and IO-delay deletes. The ICC2 SDC went from 1 452 144 lines
   (1 432 805 blank) to 19 343 lines (4 blank).
5. **not_annotated 5610** [M]: these were the 4608 assign-merged nets plus related nets. r62 PT tt/ss/ff:
   not_annotated 0, 232 752 RC nets. No separate fix was needed.
6. **GDS 140a** [M]: the kit has only `Back_End/gds/tcbn65gplus_140a/tcbn65gplus.gds`. There is no 200a GDS anywhere
   under /CMC/kits/tsmc_65nm_libs. 200a layout exists only as a Cadence cdk library
   (`Back_End/cdk/tcbn65gplus_200a`). No change.
7. **OCV/AOCV** [M]: no foundry guidance in the kit.
   - pdftotext grep (ocv|derat|on-chip variation) of every kit PDF, including the 140B databooks and release notes:
     only a false hit ("consid-erat-ions", IO pad latch-up note).
   - Text grep of all of /CMC/kits/tsmc_65nm_libs for aocv/ocv_/timing_derate: only a binary Magma volcano blob
     (an "OCV_" string).
   - The kit has no AOCV tables and no PT/ICC reference flow. No value to report; nothing applied.
8. Floorplan pin DEF `$B/pnr/r48_col/out/qb_col_blk.def` no longer exists. `col.env` COL_PIN_DEF now points to
   `$B/icc2/col/pins_r48.def`: the header plus PINS of r59's DEF, 12356 pins, which held the r48 positions fixed [M].
