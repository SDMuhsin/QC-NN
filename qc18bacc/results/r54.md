## How to resume
- Host tau5, repo copy `/tmp/ckp908/qc18bacc/r48` (sync: `rsync -a icc2 common blocks/col signoff --relative tau5:/tmp/ckp908/qc18bacc/r48/qc18bacc/flow/` from `qc18bacc/flow`).
- Run dir `$B/icc2/col/r54` (`B=/tmp/ckp908/qc18bacc/build`): design library `qb_col_blk.nlib` with block labels
  init / floorplan / place / cts / route, `summary.txt` (one block of lines per step), `<step>.log`, `rpt/`, `out/`.
- Std-cell NDM (shared): `$B/icc2/ndm/tcbn65gplus_9lmT2.ndm` (delete to rebuild).
- Steps (flow/icc2/*.tcl, wrapper `common/env.sh qb_icc2`):
  `cd /tmp/ckp908/qc18bacc/r48; [QC_PNR_FROM=<s>] [QC_PNR_TO=<s>] qc18bacc/flow/blocks/col/run.sh pnr r54`
  (s in libs init floorplan place cts route outputs; each step copies the previous label, so any step can be re-run).
- Sign-off: `run.sh post r54` (PT tt/ss/ff at 6.5 ns + ETMs; reads out/qb_col_blk.v + out/qb_col_blk_<c>_pt.spef),
  `run.sh calibre r54` (LVS source from out/qb_col_blk_pg.v, Calibre LVS / DRC / antenna on out/qb_col_blk.gds -> <run>/calibre).
- Long runs: `setsid nohup ... > $B/icc2/col/r54_<step>.out 2>&1 &`; status: `tail $B/icc2/col/r54/summary.txt`.
- After r54: flow/icc2/route.tcl filler order fixed in place (DCAP, remove violators, then FILL*), NOT run yet; the next
  run is `QC_PNR_FROM=route run.sh pnr <tag>` (after copying r54 or from cts), then post / calibre.

## What ICC2 flagged that the OpenROAD flow never did [M]
- LM-052: the 39 LEF-only cells (FILL1..64, FILL1_LL, ...) are not library cells unless kept explicitly.
- FRAM-065/066 (1 193): LEF M1 OBS becomes regular blockage touching pins (cell pin access via blockage).
- PLACE-042: no scan DEF although the netlist has scan-style flops; TCK-001: 229 ICG TE pins constant (unconstrained).
- ZRT-026: M1 / M7 / M9 pitch below wire-to-via spacing (M1 0.200 vs 0.180 / 0.225).
- ZRT antenna: 303 block-port nets skipped (ports have no gate-area antenna property).
- CHF-011: DCAP not filler-type; remove_stdcell_fillers_with_violation deleted DCAPs on M1 short / spacing (bin 3).
- write_gds: database precision 10000 by default (Calibre decks need 1000).
- v2lvs (via ICC2 netlist): case-insensitive duplicate net names (n89 / N89) in qbcw_lane_TP1_SHP1_0, qbc_pe_acc_*.
