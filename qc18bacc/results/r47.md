# R47: flow refactor (behaviour-preserving)

`impl/` (74 round dirs, 691 files) is replaced by `flow/`: one file per stage plus one config per design. 215 files were moved or merged and 476 deleted; git history is the archive.

- **Layout:** `flow/` has common/, synth/, floorplan/, place/, cts/, route/, repair/, signoff/{pt,etm,calibre} and blocks/{col,act,hub,top}. Each design has its own `<b>.env`, a flattened `<b>.cfg` and `run.sh`. How to run each design, the old -> new map and the deleted-file list are in flow/README.md.
- **Equivalence [M], single-threaded:**
  - Every OpenROAD/SDC command and sourced file was traced: 0 differences for col/act/top; for the hub, only 10 deleted report-only lines.
  - Placement dumps are identical for all four designs (col also CTS, GRT and route.guide; act also CTS).
  - Later steps were checked only by a dry run of the command lines.
  - synth/ was moved with path fixes only and never re-run.
  - Multithreaded placement is not reproducible run to run (col 223,228 vs 223,211 instances).
- **Possible bugs found, not fixed (for R48):**
  - common/or.sh exports QB_SYN=r26_ptr to every block.
  - Final act/hub run dirs source configs from snapshot paths.
  - PT hub ff uses the tt max-transition value.
  - The hub diode step uses 50 GRT congestion iterations, vs 10 in prod.
  - hold43 applies the GRT layer adjustment twice.
  - The act abs step uses the system python3.
  - r37_ssx*_ports.txt has no generator.
  - Some inputs have no recorded producing command (act DC, r35_ptr DC, col_act_pins.txt, abs7).
- **No longer regenerable:** r5d_Ctiles, r5b_blk, r36/abs4. lef57db45.tcl and etmnodrv45.tcl were deleted as unused; restore them from 2f4055b in R48.
