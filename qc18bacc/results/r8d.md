* **Fixes [M+S]** (each opt-in, default off): **WBK** (to_macro, err): every tag-derived S-write control (lane enables, addresses incl. the HQ / payload rotations, per-lane one-hot data selects, mask classes, rotation amounts, request conflict) formed from the early tags and registered: the write cycle is data AND-OR + 2 rotators (no kind / hm decode fan-out to 4 096 DB bits, no address mux before the conflict compare). The macro read / write conflict compares (S, B1 / B2) and the host-IMG check take registered port copies (m_ctx -> pass-table m_src -> ren -> compare was the next err path); err inputs registered (err +2 cycles, diagnostic only). **FFT** (act): the 128-b slice-flag find-first as a 7-level tree (was a ~40-gate ripple fp_z -> f_idx -> qb_act2). **FPR** (R8a, exact): flag port registered. **DEP** (seq, tgo): end-phase de candidates as separate adder instances (DC had shared one adder behind the compare-driven select), PPU compare as one carry-save sign per lane, token ce compares for ce_q and now in parallel.
* **Root cause of the remaining top paths [S]: DC effort, not RTL.** DC's qb_clk group WNS is the ETM-input artefact (core_in -4.5 ns), so compile_ultra leaves ripple compares / shared adders on -0.2..-0.5 ns top paths. With those pins in their own group (rpg) every top-logic class is >= 605 MHz tt (seq 496 -> 605, top_glue_x 458 -> 609) at -1.7 % logic area. **rpg0 (same hook, R8a RTL only) is as fast (>= 605 tt, ss up to +4 %)**: once the group is in the flow the R8d RTL defines buy no fmax (they cut logic 2.232 -> 2.177 mm2, +395 regs, and make err / the S-write controls robust to DC effort). Recommend `dc_grp.tcl` in the top DC flow (and the same separation in P&R repair_timing); keep the R8d defines opt-in.
* **Column-block outputs [S]** (`r8d/blk.txt`, routed R5d block on tau3): b2 and f_y are bare flop outputs; ~0.9 ns of their ETM arrival (b2 1.71, f_y 1.40 worst tt) is the block clock insertion, which DC compensates (-0.90 latency) but top PT and top CTS (plain sink) do not; the rest is distance (b2: PE row 13-15 -> south pins, 0.77 ns) and a weak u_rout flop (f_y, 0.53 ns worst / 0.19 median). **A** (top CTS: column clk pins ~0.9 ns early; PT with DC's latency): 0 RTL, 0 cycles, no re-harden: b2r > 690, head 604 tt (rpg + A). **B** `QB_COL_B2R=1` (implemented, 0 cycles, net 0 flops: b2 registered at the block pins, top b2r becomes a wire): b2 1.72 -> ~1.05-1.10 tt, but then b2 -> b2d -> map write register (0.66-0.73 ns, `xfrom`) follows the pin: est. ~500 MHz without A. **C** (P&R sizing of u_rout): f_y 1.40 -> ~1.05. Re-harden for B: ~3 h block P&R (tau3) + 45 min top DC. Recommendation: A (+ C); B only if A is not achievable in CTS.
