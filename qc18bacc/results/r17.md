# R17: per-layout line-buffer word placement (QB_ACT_LBP) -- feasibility only, **STOP** by the decision rule

**[E]** offline Python on the generator tables, no EDA, no RTL.  Scripts `impl/r17/lbp_feas.py` (main), `impl/r17/lbp_rowmap.py`
(side estimate); outputs `results/r17/feas.txt`, `results/r17/rowmap.txt`.  No QB_ACT_LBP define, no bench, no tau3 run.

## 1. Model
* Readers = home rows of the row-homed S1 registers (gen_act2_s2m.build, QB_ACT_S2M), per (layout, slot s, in-slot index j).
  Layout = what the writing pass knows: cfg 0 / 1 share one pass (A); int8 lines 33..38 -> 8i / 9i / 10i; binary cfg 10 (b7) -> 10b.
* A permutation of j, identical for all 8 slots, commutes with the slot shift (shift moves whole 2048-b slots) -- verified.
  All slots + both contexts + the pre-mux of one index then sit at one physical row (4 indices per act row).
* Crossings of horizontal cuts between act rows = 32 b x rows spanned by each net (lbm word -> its S1 readers, union over
  all layouts, since it is one net); write net = rdq / sdq group -> the rows it can be written to.

## 2. Is the required mapping slot-independent?  **No, for the multi-row-tile layouts** [E]
| layout | j used | j with slot-dependent reader rows | multi-reader words (same s, j) | span over slots of one j (mean / max) |
|---|---|---|---|---|
| A (cfg 0/1) | 64 | 0 | 12 (tile halo x 15/16: row 15 for cfg 0, row 0 for cfg 1) | 0.94 / 15 |
| 2, 9i | 64 | 24 / 26 | 0 | 0.4 / 1 (harmless) |
| 3, 4 | 32 / 64 | 0 | 0 | 0 / 0 |
| **5** | 64 | 64 | 64 | **8.4 / 9** |
| **6** | 32 | 32 | 0 | **8.1 / 9** |
| **7** | 64 | 64 | 128 | **8.0 / 8** |
| **10b** (b7, W 4) | 64 | 64 | 256 | **12.0 / 12** |
| 8i / 10i | 64 | 0 | 24 / 64 | 1.5 / 6.0 |

Mechanism: in tiles of 2 output rows (cfg 5 / 6 / 7) act row r = 8 oyr + ox, and the slot (input image row) decides oyr, so
the same j is read near row ox in one slot and near row 8 + ox in another; slots shared by both output rows (cfg 5 slot 2,
cfg 7 slots 1 / 2) are read 8 rows apart within one word.  cfg 10 binary (4 x 4 map, r = 4 oy + ox, slot = iy) reads every
word from up to 3 output rows 4 apart (span 12 over slots).  The PI's per-word statistic (cfg 6 / 7 "span 0 / 4") is per
(slot, j); the slot dimension is where the long wires are, and a write-side permutation of j cannot touch it.

## 3. Numbers and decision [E]
| | current (fixed order) | LBP (best found) | bound, any slot-independent permutation |
|---|---|---|---|
| S1 crossings (PI metric / consistent) | 78 304 / 80 256 | 88 160 (+9.8 %) | 57 344 (-28.5 %; layout 10b alone) |
| write network, source free / south pin | 736 / 12 896-31 360 | 18 816 / 31 168 | - |
| S1 + write (source free) | 80 992 | 106 976 (**+32 %**) | > 57 344 (< 29 % drop even with a free write side) |
| write candidates per physical word | 2 (rdq, sdq) | max 10, mean 7.4 (rdq 4.5 + sdq 2.9) | - |
| S1 terms (128 regs) | 1 470, max 33 | 1 584, max 34 (x1.08) | - |

* Residual of the LBP placement by layout (S1 crossings of its words alone): 10b 62 976, 7 49 152, 5 48 768, 10i 12 288,
  6 8 320, A 5 760, 8i 3 776, 2 2 240, 9i 960, 3 / 4 0.  Every physical index carries a 5 / 7 / 10b word, so the union span
  per lbm net stays ~8-12 rows: placing the single-reader layouts locally buys nothing.
* Even a slot-dependent placement (each (s, j) free; does not commute with the shift) keeps 49 152 (10b within-word spans).
* **Decision: STOP** (rule: >= 40 % drop of S1 + write with fan-in <= 1.3x; fan-in passes, crossings get worse, and the
  bound for any slot-independent permutation is 28.5 % on S1 alone).  So no QB_ACT_LBP RTL, mutant, bench or tau3 probe.

## 4. Side estimate and next [E / R]
* `lbp_rowmap.py`: measured on act-unit rows, interleaving the act-row map of multi-row tiles (r = 2 ox + oyr for cfg 5-9,
  4 ox + oy for cfg 10) shrinks cfg 5 / 6 / 7 bounds 51.8 k / 8.2 k / 59.9 k -> 13.3 k / 1.0 k / 32.8 k, but cfg 10b stays
  61.4 k (2-D 3x3 halo of a 4 x 4 map on a 1-D row order), so no 1-D relabelling + permutation reaches 40 % either.  It
  would also change the pixel -> array-row order (compiler / output side).
* The long S1 wires are the 3x3 halo between output rows of one tile (and the cfg 0/1 tile halo), i.e. the same lb word is
  needed by 2-3 act rows 4-12 apart.  Fixes that address that: a local copy of lbm per act-row band (R16 next 1a, write or
  pre-mux duplication: area / flops cost vs the HW constraint) or an S1 that is not wire-limited (R16 next 1b).
